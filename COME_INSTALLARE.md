# 📱 Come Installare Tybelos Circle su Cellulare e PC

## ✅ SOLUZIONE IMMEDIATA - App Web Funzionante

### 📲 SU CELLULARE (Android/iPhone)

#### Metodo 1: Apri il file HTML
1. **Scarica** il file `tybelos-circle-app.html`
2. **Apri** con il browser (Chrome, Safari, Firefox)
3. Vedrai un pulsante **"Installa"** in alto a destra
4. Tocca **"Installa"** o aspetta il popup automatico
5. L'app verrà aggiunta alla schermata home!

#### Metodo 2: Da Server Web
Se vuoi hostare online:
```bash
# Opzione A: Python SimpleHTTPServer
python3 -m http.server 8000

# Opzione B: Node.js http-server
npx http-server -p 8000

# Poi apri dal cellulare:
# http://TUO-IP:8000/tybelos-circle-app.html
```

---

### 💻 SU PC (Windows/Mac/Linux)

#### Installazione come App Desktop:

**Chrome/Edge:**
1. Apri `tybelos-circle-app.html` in Chrome
2. Clicca sui tre puntini (⋮) in alto a destra
3. Seleziona **"Installa Tybelos Circle"** o **"Crea collegamento"**
4. L'app si aprirà in una finestra separata
5. Troverai l'icona nel menu Start (Windows) o Applicazioni (Mac)

**Safari (Mac):**
1. Apri il file in Safari
2. File → Aggiungi al Dock
3. L'app appare nel Dock

**Firefox:**
1. Apri il file in Firefox
2. L'app funziona ma non si può installare (limitazione Firefox)
3. Aggiungi ai Preferiti per accesso rapido

## 📖 GUIDA PASSO-PASSO DETTAGLIATA

### 🍎 iPhone/iPad

1. **Apri Safari** (deve essere Safari, non Chrome!)
2. Apri il file `tybelos-circle-app.html`

6. L'icona appare nella schermata home
7. Apri l'app dalla schermata home
8. **Dai permesso al microfono** quando richiesto

## ❓ Risoluzione Problemi

### Il microfono non funziona
- ✅ Controlla permessi browser per microfono
- ✅ Chrome → Impostazioni → Privacy → Microfono
- ✅ Assicurati di usare HTTPS o localhost
- ✅ Prova a ricaricare la pagina

### Il pulsante "Installa" non appare
- ✅ Usa Chrome o Safari (non Firefox)
- ✅ Apri il file con protocollo HTTP/HTTPS (non file://)
- ✅ Aspetta 3 secondi (popup automatico)
- ✅ Menu browser → "Installa app"

### L'app non parla
- ✅ Controlla volume dispositivo
- ✅ Controlla permessi audio browser
- ✅ Alcuni browser richiedono interazione utente prima

### Errore "Speech recognition not supported"
- ✅ Usa Chrome o Safari (meglio supportati)
- ✅ Assicurati di avere connessione internet
- ✅ Aggiorna browser all'ultima versione
